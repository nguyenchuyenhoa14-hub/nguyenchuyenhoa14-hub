## Research & Key Projects

* **[CRYPTO_SOC](https://github.com/BAT-LAB69/CRYPTO_SOC)** (Collaborative Design)
  * Full-stack Cryptographic System-on-Chip featuring custom bus interconnects and hardware security IP streaming.
  * *Features:* TRNG, SHAKE128/256, AES-CBC, Ed25519 digital signatures, and Post-Quantum Cryptography (BIKE KEM).
  * *Role:* Co-designed Verilog custom bus interconnect adapters and DMA controllers for low-latency hardware IP streaming.

* **[YOLOv8-FPGA-Accelerator](https://github.com/nguyenchuyenhoa14-hub/YOLOv8-FPGA-Accelerator)**
  * Custom FPGA Detection Head accelerator for YOLOv8 on Zynq-7020 FPGA.
  * *Features:* Memory-based focal loss lookup decoder, division-free bounding-box suppression (NMS), and INT8 quantization.
  * *Metrics:* 32.1 FPS @ 105 MHz, 0.302 W PL dynamic power, 10 DSP blocks total. Accepted at IAAA 2026.

* **[Zynq-True-Random-Number-Generator](https://github.com/nguyenchuyenhoa14-hub/Zynq-True-Random-Number-Generator)**
  * Compact Jitter-Sampling TRNG using Latch-XOR oscillator cells on Arty Z7-20 FPGA.
  * *Features:* ARM Cortex-A9 AXI bus readout, STM32 UART verification, NIST SP 800-22 certified.

* **[RISCV-RV32I-Pipelined-Processor](https://github.com/nguyenchuyenhoa14-hub/RISCV-RV32I-Pipelined-Processor)**
  * 5-stage pipelined RV32I RISC-V processor designed in Verilog HDL.
  * *Features:* Forwarding unit, hazard stall/flush logic, timing-clean synthesis at 125 MHz on Artix-7, Python co-simulation framework.

* **[Volumetric-MultiView-Triangulation](https://github.com/nguyenchuyenhoa14-hub/Volumetric-MultiView-Triangulation)**
  * Terrain-independent 3D object geolocation system for monocular UAVs.
  * *Features:* Multi-ray frustum intersection pipeline, 22.6% error reduction over single-ray baselines. Accepted at IAAA 2026.
